קטלוג פריטים

פריט "לאורח" מוכפל אוטומטית במספר האורחים. אפשר לשייך פריט ללוקיישן מסוים.

קישור חתימה ללקוח

חיבור חד-פעמי לחשבון Google שלך. אחריו כל הצעה שמורה מקבלת קישור שהלקוח פותח בטלפון, רואה את ההצעה וחותם. האישורים נשמרים בגיליון Google ומגיעים אליך במייל. עדיף לעשות את זה ממחשב.
  1. פתח את sheets.new כדי ליצור גיליון Google חדש, ותן לו שם, למשל "אישורי הצעות מחיר".
  2. בתפריט של הגיליון: תוספים (Extensions) ← Apps Script.
  3. בקובץ Code.gs מחק את מה שיש, לחץ כאן על העתק Code.gs והדבק. הקוד כבר כולל את המפתח הסודי שלך ואת המייל להתראות.
  4. לחץ על + ליד "קבצים" ← HTML, קרא לקובץ בדיוק Sign, מחק את מה שיש והדבק:
  5. שמור (אייקון הדיסק), בחר למעלה את הפונקציה setup ולחץ Run. Google תבקש הרשאות: Review permissions ← בחר את החשבון ← Advanced ← Go to… ← Allow. זה הקוד שלך, ולכן Google מציגה אזהרה.
  6. Deploy ← New deployment ← סוג: Web app. "Execute as": Me. "Who has access": Anyone. לחץ Deploy.
  7. העתק את ה-Web app URL (מסתיים ב-/exec), הדבק אותו כאן ולחץ "שמור הגדרות".
שינית את המייל? העתק שוב את Code.gs, הדבק במקום הישן, ואז Deploy ← Manage deployments ← עריכה ← Version: New version.
