# מדריך שימוש באפליקציה (לשרון)

כל סעיף: כותרת, למי הוא (apps = הרשאות, depts = מחלקות, all = כולם), page = העמוד, ואז השלבים.
מטרות להצגה על המסך כתובות כך: {act:שם} או {id:שם} = כפתור מסוים, {text:טקסט} = כפתור או כותרת עם הטקסט הזה.
העמוד הראשי נפתח מהתפריט ☰ למעלה {act:menu}.

## הפעלת התראות בטלפון
apps: all
page: avail
1. פותחים את התפריט ☰ למעלה {act:menu}.
2. לוחצים "🔔 הפעלת התראות" {act:notif-on} ומאשרים בחלון של הטלפון.
3. באייפון: קודם מוסיפים את האתר למסך הבית (שיתוף ← "הוספה למסך הבית"), פותחים מהאייקון, ורק אז מפעילים התראות.
אם הכפתור לא מופיע בתפריט, ההתראות כבר פעילות במכשיר הזה.

## הגשת זמינות למשמרות (עובד)
apps: all
page: avail
1. בתפריט ☰ בוחרים "סידור עבודה", ובלשונית "הזמינות שלי" {text:הזמינות שלי}.
2. מסמנים את המשמרות שמתאימות לך בשבוע שפתוח להגשה (לחיצה על משמרת מסמנת אותה).
3. אפשר לכתוב הערה למנהל ולבחור כמה משמרות מקסימום בשבוע.
4. לוחצים "שליחה למנהל" {act:my-send}. אם אין זמינות בכלל, אותו כפתור שולח "אין לי זמינות השבוע".
אחרי שהמנהל פרסם את הסידור אי אפשר לשנות זמינות לאותו שבוע.

## לראות את המשמרות שלי ולבקש החלפה
apps: all
page: mine
1. לשונית "המשמרות שלי" {text:המשמרות שלי}.
2. ליד משמרת עתידית לוחצים "בקשת החלפה" {act:sw-open}.
3. בוחרים עמית מאותה מחלקה (ואפשר גם משמרת שלו בתמורה) ולוחצים "שליחת הבקשה" {act:sw-send}.
4. העמית מאשר אצלו, ואז המנהל מאשר. עד אז אפשר "ביטול בקשה" {act:rq-cancel}.
כאן גם מאשרים בקשות שהמנהל שלח לך לשינוי משמרת.

## בניית סידור עבודה (מנהל משמרות)
apps: shifts, dept
page: sched
1. "סידור עבודה" בתפריט, לשונית "סידור" {text:סידור}.
2. בוחרים שבוע עם החצים למעלה.
3. כדי שעובדים יגישו זמינות: "פתיחת השבוע להגשת זמינות" {act:openweek}.
4. לראות מי הגיש: "מה העובדים הגישו" {act:subs-open}.
5. שיבוץ: לוחצים על משבצת בטבלה ובוחרים עובד, או "שיבוץ אוטומטי" {act:auto} (משבץ רק עובדים של המלון הזה).
6. כשמוכן: "פרסום לעובדים" {act:publish}. העובדים מקבלים התראה.
אחרי פרסום שינויים עוברים כבקשות שהעובד מאשר.

## הוספת עובד ושיוך מחלקות

page: hr

2. עובד חדש נרשם לבד עם קוד הצטרפות. הקוד נמצא בכרטיס "קודי הצטרפות" בתחתית העמוד {text:קודי הצטרפות}, ו"העתקה להודעה" {act:jc-copy} שולח אותו בוואטסאפ.
3. אפשר גם "הוספת עובד ידנית" {act:emp-new}.
4. לוחצים על עובד כדי לפתוח את הכרטיס: מחלקות, סוג עובד, שכר, תפקיד והרשאות, ושומרים {act:emp-save}.
5. בכרטיס יש גם "פרטי כניסה" ואיפוס סיסמה למי שנכנס עם שם משתמש.

## דוח סוף משמרת בקבלה
apps: front
page: front
1. בתפריט "קבלה" {text:קבלה}.
2. גוללים לטופס דוח המשמרת: בוחרים את עצמך, משמרת, ממלאים קופה (420 והפקדה), אשראי, הודעות בוקינג שלא נענו, בקשות ארסונה, ומה שנדרש לפי המשמרת (בלילה: צ׳ק אין / אאוט).
3. האם הקבלה והבר נקיים: "כן" מחייב צילום.
4. "שליחת הדוח" {act:sr-save}. אפשר "שמירת טיוטה" {act:sr-draft} ולהמשיך אחר כך. הטיוטה גם נשמרת לבד כל כמה שניות.
5. אם שולם מהקופה מול חשבונית: מצלמים אותה בחלק "שולם מהקופה מול חשבונית" ורושמים סכום.
